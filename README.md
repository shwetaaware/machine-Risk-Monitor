# Machine Failure Prediction System

 Overview
A Python-based machine condition monitoring system that evaluates machine readings and identifies potential warning conditions using predefined rules.

Features
1) Machine identification using unique IDs
2) Temperature, vibration, and RPM input
3) Input validation
4) Rule-based machine health classification
5) Automatic report storage
6) View and search previous machine reports

Technologies Used
1) Python
2) Functions, loops, lists, and conditional statements
3) Exception handling and file handling

How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Run `python main.py` in your terminal.
4. Follow the menu instructions.

 Important Note
This is an educational, rule-based monitoring project. It does not use a trained machine-learning model, and its illustrative thresholds must not be treated as universal industrial safety limits.
